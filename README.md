## tags

- html guarda a pagina toda
- head configuraçao da pagina
- meta faz os acento funciona
- title nome na aba do navegador
- link liga o css
- body tudo que aparece na tela
- header parte de cima do site
- nav menu com os botao
- main conteudo principal
- section cada parte da pagina
- article cada produto
- footer rodape
- div caixa pra agrupa as coisa
- h1 titulo principal
- h2 titulo de cada parte
- h3 titulo menor
- p texto
- strong texto em destaque
- img imagem
- a link pra outra pagina
- form formulario
- label nome do campo
- input campo pra escreve
- textarea campo grande da menssagem
- button botao de envia
